# Repeato frontend (React (JavaScript) + Vite)
npm install && npm run dev
- Customer app (mobile-first): http://localhost:5173/
- The main page provides separate Customer login and Owner login options.
- Owner dashboard opens after signing in through the owner login demo form.
Customer sign-up and sign-in use email and password. Authentication and rewards are demo-only; connect a real auth provider and database before using real accounts.
Light/Dark toggle top-right. Dashboard and customer data are mocked.
Purchase-verification mechanism is still an open decision in the doc, so Scan/Tap is a placeholder.
